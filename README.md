# Twin Lanterns — Spot the Difference

A cozy six-scene illustrated difference hunt with original canvas art, synthesized chimes, combo scoring, hints and a lantern-lit campaign.

Run locally with Node 22: `node serve.ts`, then open `http://localhost:8080`. To make the hand-in output, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.

Mouse or arrow keys move and click or Enter checks a spot. H hints, P/Escape pauses, M mutes and R restarts.
